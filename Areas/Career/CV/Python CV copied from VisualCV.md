### PriceBreaker, a Price monitor system

For "SaymanDigital" as an e-commerce platform for selling digital goods, It was important to know about its competitor's prices, so it can always set a competitive price or offer discounts to its customers. PriceBreaker was a solution to define a competitor's website and products so it can scrap the defined website and grab the price for each product.

I used Python Django to create an administration panel for registering competitor's websites and their products that needs to be monitored. Then using Python Requests and Beautiful Soup packages I scrap the website and grab the price. As I have our own price for each product I compare the prices and notify the admins when there is a lower price for a product.

Also, I created a parser to parse strings like `.className #ID .priceClass` so the admin can define what should be scrapped in the structure of each website.
