# Experiences

## PriceBreaker, a Price monitor system

For "SaymanDigital" as an e-commerce platform for selling digital goods, It was important to know about its competitor's price, so it can always set a competitive price or offer discounts to its customers. PriceBreaker was a solution to define a competitor's website and products so it can scrap the defined website and grab the price for each product.

I used Python Django to create an administration panel for registering competitor's websites and their products that needs to be monitored. Then using Python Requests and Beautiful Soup packages I scrap the website and grab the price. As I have our own price for each product I compare the prices and notify the admins when there is a lower price for a product.

Also, I created a parser to parse strings like `.className #ID .priceClass` so the admin can define what should be scrapped in the structure of each website.

## Social media image generator for marketing

To scale up the amount of social media posts and speed up the process of creating social media posts for the marketing and content team, I created a Python Flask web interface so a member of the marketing team can choose one of the predefined templates and enters product title or any necessary text and hit a button to get the ready-to-share image for social media.

Besides Python flask, I used PIL image library to make uploaded image transparent and add image or text on the base template images.

## Sales and support process automation

For an e-commerce platform which has more than 30K visits daily, it was necessary to facilitate and automate some of the sales and support processes. Two main aspects of this automation are registering imported goods in government panels for tax and customs and cross-checking customer's identities with banks to avoid fraud on payments.

The major problem was that for these both aspects, there was no API. So in order to accomplish this automation I used Python with Selenium to simulate what a operator does on the web panels.

Also to check the result and status of the automated jobs, I created a web admin panel with Python Flask.
