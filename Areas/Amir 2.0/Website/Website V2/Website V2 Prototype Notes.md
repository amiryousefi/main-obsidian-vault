# website-v2 (futuristic premium concept)

This folder contains a narrative-first, futuristic design concept for your next personal website direction.

## Files
- `index.html` - content-rich personal homepage
- `how-i-think.html` - field principles and approach page
- `case-studies.html` - case studies index page
- `case-oxin.html` - Oxin detailed case page
- `case-todayscrypto.html` - TodaysCrypto detailed case page
- `case-sayman.html` - Sayman detailed case page
- `services.html` - services overview page
- `products.html` - products page (available + coming soon)
- `book-call.html` - qualification-first conversion page
- `style-guide.html` - visual system preview page
- `styles.css` - original v2 style layer
- `styles-personal.css` - personal-first style layer
- `assets/hero-grid.svg` - hero systems graphic
- `assets/orbit-mark.svg` - orbit identity mark
- `assets/data-stream.svg` - divider/data flow graphic
- `assets/amir-yousefi-hero-*.webp/.jpg` - optimized portrait assets

## Run locally
From repository root:

```bash
python3 -m http.server 8080
```

Open:

`http://localhost:8080/code/website-v2/index.html`
