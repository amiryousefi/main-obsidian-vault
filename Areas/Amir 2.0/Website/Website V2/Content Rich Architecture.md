# Website V3 content-rich architecture

Date: May 28, 2026  
Purpose: define a content-rich structure that is personal, informative/inspiring, and promotional.

## Mission (3-purpose model)
The website must simultaneously:
1. **Introduce Amir** (identity, credibility, worldview)
2. **Inform + inspire** (genuine ideas, principles, field approaches)
3. **Promote work** (products and services with clear next steps)

---

## 1) Recommended site map (content-rich)

## Home (personal-first)
- Hero (identity + emotional signal)
- My story (professional humanized timeline)
- How I think (principles + real-world framing)
- Proof highlights (Oxin -> TodaysCrypto -> Sayman)
- Ideas teaser (latest field principles)
- Work teaser (services + products)
- CTA block (Book a strategy call, calm invitation)

## About
- Full story, operating style, values in action
- "How I make decisions" section
- Public profile links

## How I Think
- Field Principles (core principles)
- Field Notes (real project lessons)
- Decision frameworks / approach cards

## Case Studies
- Index page + 3 detail pages:
  - Oxin
  - TodaysCrypto
  - Sayman

## Services
- Advisory offers and engagement flow
- Selective/exclusive positioning language

## Products
- E-books, templates, playbooks, micro-products
- "Coming soon" structure allowed for phase 1

## Book a Strategy Call
- Qualification-first form
- Clear fit criteria
- Private pricing note

---

## 2) Homepage proof order (confirmed)
1. Oxin
2. TodaysCrypto
3. Sayman

Case card style:
- concise and lead-generating
- 1 challenge hook + 1 outcome hook
- explicit "Read full case" link

Field principles exposure:
- show **3 principles** on homepage
- link to a dedicated full "How I Think / Field Principles" page

---

## 3) CTA strategy (recommended)

Primary CTA text:
- **Book a strategy call** (keep)

Reason:
- stronger premium signal than softer alternatives
- still workable if framed with qualification and calm invitation copy

Suggested supporting microcopy:
- "Selective advisory engagements each quarter."
- "If there is a fit, we can map your next strategic move in one focused call."

---

## 4) Content richness framework per page

Each major page should contain:
- one identity/narrative block
- one practical framework block
- one proof block
- one clear next-step action

This prevents pages from being either:
- purely personal with no conversion path, or
- purely sales with no soul.

---

## 5) "Soul" implementation guidelines

To make the site feel personal but professional:
- use first-person narrative lines where meaningful
- include field-tested statements, not generic motivational copy
- pair every principle with a practical example or decision pattern
- keep visuals in service of story and meaning

---

## 6) V3 build sequence (recommended)
1. Home V3 rewrite (personal-first + content-rich blocks)
2. Create "How I Think" page
3. Create 3 case detail pages
4. Create Products page
5. Wire homepage cards to all detail pages

---

## 7) Current implementation choices (confirmed)
- Homepage includes 3 principles + "Read all principles" link.
- Case studies have dedicated detail pages per case.
- Products page uses **Available / Coming soon** presentation style.
- Testimonials appear as editable sample quotes until final references are approved.
- CTA retains "Book a strategy call" with exclusivity microcopy:
  - "Selective advisory engagements each quarter."
