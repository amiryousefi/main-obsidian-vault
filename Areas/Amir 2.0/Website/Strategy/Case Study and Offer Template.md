# Case study and offer template

Use this file to expand your strategy into website content and client-facing assets.

## A) Case study template (copy for each project)

### Project name
- Example: TodaysCrypto / Sayman / Oxin Game Club

### Client/profile type
- Startup / scale-up / established
- Industry:
- Region:

### Context
- What was broken, blocked, or unclear?
- What business goal required technical/product changes?

### Your role
- Advisor / CTO / lead developer / team lead / builder
- Scope ownership:
  - strategy
  - architecture
  - team/process
  - implementation

### Actions taken
- Key decisions you made
- Systems/processes you introduced
- Product/technical interventions

### Outcome and impact
- Quantitative outcomes (preferred)
  - performance
  - delivery speed
  - revenue/cost
  - retention
- Qualitative outcomes
  - team maturity
  - decision quality
  - long-term sustainability

### Proof assets
- Links, screenshots, architecture diagrams, testimonials

### One-line headline
- "I helped X achieve Y by doing Z."

## B) Offer card template

### Offer name

### Best for
- Who this is for and when to buy it.

### What is included
- 3 to 7 clear deliverables.

### Timeframe
- Example: 1 week / 2 weeks / monthly

### Output format
- Call / report / roadmap / implementation plan

### Pricing model
- Fixed / retainer / call bundle
- Public price / starting from / private

### CTA
- Book a call / Request audit / Apply now

## C) Qualification questions for lead form

1. What is your business and stage?
2. What is your biggest current product/tech bottleneck?
3. What is the impact of not solving it in the next quarter?
4. What is your available budget range?
5. Preferred engagement type:
   - Advisory only
   - Advisory + implementation
   - Team/process coaching
6. Region/time zone and preferred language
