# Case study skeletons (V1)

Use this file to turn project experience into public case studies.

## Universal structure (for each case)

1. Client context  
2. Initial challenge  
3. Role and scope  
4. Strategic decisions made  
5. Execution highlights  
6. Outcomes (metrics + qualitative)  
7. Lasting impact  
8. What this proves for future clients

## Case study writing rules (for final publish)

- Focus on outcomes and decisions, not tool lists.
- Keep each case scannable (short sections, strong headings).
- Use numbers where possible ("before -> after").
- Include one strategic lesson per case.
- End each case with a CTA:
  - "If you are facing similar challenges, book a strategy call."
