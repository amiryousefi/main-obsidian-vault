# website-v1 (static draft)

This folder contains a first-pass static implementation of the Website V1 plan.

## Included pages
- `index.html`
- `services.html`
- `case-studies.html`
- `about.html`
- `book-call.html`
- `styles.css`

## Run locally
From repo root:

```bash
python3 -m http.server 8080
```

Then open:

`http://localhost:8080/code/website-v1/index.html`

## Notes
- This is intentionally static for fast iteration.
- Form submission and scheduling are placeholders in V1.
- Next implementation step can migrate this content into the final chosen framework.
