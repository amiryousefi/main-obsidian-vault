## خلاصه مدیریتی

**ایران حافظه** یک اسکریپت فروشگاه اینترنتی (E-Commerce) است که برای فروش خرده‌ای محصولات دیجیتال و جانبی (شارژر، پاوربانک، هدفون، اسپیکر و …) طراحی شده است.

| مشخصه | توضیح |
|--------|--------|
| **فریم‌ورک** | Laravel 7/8/9 |
| **پایگاه داده** | MySQL / MariaDB |
| **رابط کاربری** | Blade + JavaScript (RTL، فارسی) |
| **اپ موبایل** | REST API با Laravel Sanctum |
| **برند** | ایران حافظه (imc V.B) |

سیستم سه لایه دارد: **فروشگاه عمومی**، **پنل ادمین** (مدیریت کامل)، و **پنل فروشنده** (چندفروشندگی). جریان خرید از مرور محصول تا پرداخت آنلاین، پیگیری سفارش، و ارسال پستی پوشش داده شده است.

## ۱. فروشگاه (بخش مشتری)

### صفحه اصلی
- **اسلایدر هیرو** — بنرهای دسته‌محور با عنوان و زیرعنوان فارسی و نمایش محصولات منتخب
- **دسته‌بندی‌های ویژه** — کارت‌های میانبر زیر اسلایدر
- **پیشنهاد ویژه** — اسلایدر تخفیف با تایمر شمارش معکوس
- **جدیدترین محصولات** — ریل محصولات تازه
- **ویترین دسته‌ها** — بنر + اسلایدر برای هر دسته (شارژر، پاوربانک، هدفون، …)
- **محصولات منتخب / پرفروش / محبوب** — بر اساس فروش و علاقه‌مندی
- **نوار برندها** — نمایش برندهای شاخص
- **بلاگ** — اتصال به وبلاگ WordPress خارجی
- **PWA** — `manifest.json` برای نصب روی موبایل

### کاتالوگ و محصول
- مرور دسته‌بندی با URL فارسی: `/محصولات/...`
- لیست کلی محصولات: `/shop`
- **صفحه محصول** با:
  - انتخاب تنوع (رنگ، ظرفیت، …)
  - وضعیت موجودی: **موجود** / **ناموجود** / **پیش‌فروش** / **پیشنهاد ویژه**
  - گالری تصویر، محصولات مرتبط
  - تب‌ها: **مشخصات فنی**، **فروشندگان**، **نظرات**، **نمودار قیمت**
  - **مقایسه محصول** (تا ۴ کالا)
  - **گارانتی ۲۴ ماهه آونک**
  - **تضمین ثبت رجیستری** (برای گوشی)
  - SEO و JSON-LD

### جستجو
- صفحه جستجو با فیلتر: دسته، برند، بازه قیمت، موجودی، فقط تخفیف‌دار
- مرتب‌سازی: جدیدترین، ارزان‌ترین، گران‌ترین، مرتبط‌ترین
- API: جستجو، autocomplete، دسته‌های پیشنهادی

### سبد خرید و تسویه
- افزودن/حذف/تغییر تعداد
- نشانگر تعداد در هدر
- **تسویه حساب** (`/checkout`): انتخاب آدرس، روش ارسال، کد ملی، روش پرداخت
- ارسال **پیش‌کرایه** یا **پس‌کرایه**
- اعمال **کد تخفیف / rebate**
- صفحات موفقیت/خطای پرداخت
- هدایت به درگاه بانکی

### حساب کاربری
- **پیشخوان** — داشبورد کاربر
- **سفارش‌ها** — تاریخچه و جزئیات فاکتور
- **آدرس‌ها** — CRUD با استان/شهر ایران
- **علاقه‌مندی‌ها**
- **تغییر رمز** و **تأیید موبایل**
- لغو سفارش

### احراز هویت
- ورود با **OTP** (کد یکبار مصرف پیامکی)
- ورود با **رمز عبور**
- ورود با **Google**
- ثبت‌نام و بازیابی رمز از طریق SMS

### سایر بخش‌های فروشگاه
| بخش | مسیر / توضیح |
|-----|--------------|
| مقایسه محصول | `/compare` — جدول کنار‌به‌کنار |
| علاقه‌مندی | `/favorites` — لیست و نشانگر هدر |
| نظرات | ثبت و پاسخ روی محصول/فروشگاه |
| صفحات ثابت | تماس، درباره ما، FAQ، حریم خصوصی، قوانین، مرجوعی، راهنمای خرید |
| لندینگ‌های بازاریابی | `/landing/bags`, `/landing/driving` |
| رویدادهای تبلیغاتی | `/events/{slug}` — قالب‌های سفارشی (مثل یلدا) |
| خبرنامه | API عضویت |
| Sitemap | XML برای SEO |

## ۲. پنل مدیریت

مسیر پایه: `/admin` — ورود با موبایل و رمز عبور.

### داشبورد
- KPI: کاربران، سفارشات پرداخت‌شده/نشده، محصولات، درآمد ماهانه
- نمودار سفارش و درآمد روزانه (تقویم **جلالی**)
- سفارشات اخیر
- نشانگر: سفارشات در حال تامین، نظرات در انتظار، یادداشت‌های خوانده‌نشده

### کاربران
| زیرمنو | کاربرد |
|--------|--------|
| مدیریت مدیران | CRUD ادمین‌ها |
| مدیریت تامین‌کنندگان | CRUD فروشندگان |
| مدیریت مشتریان | CRUD خریداران |
| نقش‌ها و دسترسی‌ها | RBAC |
| دپارتمان‌ها | ساختار سازمانی |

### محصولات
- افزودن/ویرایش/حذف محصول
- **محصول ترکیبی (باندل)**
- دسته‌بندی سلسله‌مراتبی
- برند، برچسب، ویژگی‌های خاص
- **استخراج مشخصات** از GSM Arena و Zoomit
- SEO با آنالایزر Yoast
- عملیات گروهی (bulk)
- کپی محصول

### قیمت‌گذاری
- لیست قیمت (تنوع‌ها / variations)
- افزودن قیمت
- **ویرایش گروهی قیمت**
- به‌روزرسانی SKU

### سفارشات
- چرخه وضعیت: در انتظار ← تأیید ← **تامین** ← بسته‌بندی ← ارسال ← تکمیل / لغو / مرجوعی
- **داشبورد تامین** — برای پرسنل انبار
- **سریال‌گذاری** روی خطوط فاکتور
- **بسته‌های پستی** — کد رهگیری، SMS، چاپ برچسب
- تب‌ها: اطلاعات سفارش، تراکنش‌ها، مرسوله‌ها، یادداشت، SMS، گزارش
- **امتیاز KYC** — ارزیابی ریسک تقلب
- تأیید حسابداری
- خروجی Excel و چاپ فاکتور

### گروه سفارش
- گروه‌بندی فاکتورها برای پردازش دسته‌ای و همگام‌سازی حسابداری

### امور مالی
- مدیریت تراکنش‌ها
- **Import تراکنش بانکی** (Excel)
- ابزار تطبیق و بررسی فاکتور

### ملزومات
- ویژگی‌های محصول (attributes)
- **تخفیف‌ها / rebate**
- واژه‌نامه (ترجمه نام محصول)

### نظرات
- صف تأیید
- قالب‌های پاسخ و برچسب نظر
- عملیات گروهی

### مدیریت سایت
| ماژول | کاربرد |
|-------|--------|
| اعلان‌ها | SMS، ایمیل، Web Push، App Push |
| بنرها | بنرهای تبلیغاتی |
| رویدادها | کمپین با چرخش محصول زمان‌بندی‌شده |
| ریدایرکت‌ها | مدیریت URL |
| روش پرداخت | پیکربندی درگاه‌ها |
| اسلایدرها | اسلایدرهای قدیمی |
| **تنظیمات صفحه اصلی** | اسلاید هیرو، دسته‌های ویژه، ردیف دسته‌ها |
| منوها | سازنده منوی ناوبری |
| تم | حالت روشن/تاریک |
| تنظیمات اپ/وب | پیکربندی کلاینت موبایل و وب |
| تنظیمات فروش | قوانین CO، دسته‌های ممنوع |

### سایر
- فروشگاه‌ها (چندفروشندگی)
- کوپن و تخفیف قانون‌محور
- خبرنامه
- تیکت / یادداشت داخلی
- Audit Log
- گزارش فروش (پرفروش‌ترین محصولات و تنوع‌ها)

## ۴. زیرساخت فنی

### درگاه‌های پرداخت
- **ملت**، **سامان**، **سداد** (وب + موبایل)
- پشتیبانی از زرین‌پال، ایران‌کیش، پارسیان و … (پیکربندی)
- Callback و لاگ وضعیت تراکنش

### ارسال
- انواع روش ارسال با قوانین هزینه
- تقسیم مرسوله (parcel) per خط فاکتور
- چاپ برچسب پستی
- استان/شهر ایران

### اطلاع‌رسانی
| کانال | سرویس |
|-------|--------|
| SMS | FaraPayamak، SmsIr |
| ایمیل | Mailable |
| Web Push | Najva |
| App Push | FCM، Pushe |
| صف | SendSmsJob |

### API موبایل (`/api`)
- init، home settings، محصول، دسته، برند
- احراز هویت (Sanctum)
- سبد، checkout، پروفایل
- بلاگ، خبرنامه، compare

### همگام‌سازی حسابداری
- API `/api/accsyc/*` — ارسال گروه فاکتورهای تکمیل‌شده به سیستم حسابداری خارجی

### دستورات Artisan (واردات و نگهداری)
| دستور | کاربرد |
|-------|--------|
| `products:import-imc-vb` | واردات از کانال تلگرام @imc_vb |
| `products:import-takht` | واردات از Takht Jamshid |
| `import:wp` | مهاجرت کامل از WordPress/WooCommerce |
| `home:seed-hero-slides` | seed اسلاید هیرو |
| `home:seed-featured-categories` | seed دسته‌های ویژه |
| `product:update-prices` | به‌روزرسانی گروهی قیمت |
| `rebates:expire` | انقضای کدهای تخفیف |
| `otp:cleanup` | پاکسازی OTP |

### امنیت
- OTP، Google OAuth، Sanctum
- نقش و دسترسی (RBAC)
- **KYC** — تطبیق کد ملی و آدرس، تاریخچه پرداخت
- Audit trail روی مدل‌ها

### SEO و محتوا
- Sitemap XML
- Meta و JSON-LD
- آنالایزر Yoast در ادمین
- URL فارسی برای دسته‌ها

## ۵. قابلیت‌های ویژه

- **دو تم موازی:** تم جدید `home/` (صفحه اصلی، محصول، سبد) + تم legacy `web/default` (checkout، برخی پروفایل)
- **HomeComposer** — سکشن‌های داده‌محور صفحه اصلی با fallback خودکار
- **KYC امتیازدهی** — تشخیص ریسک قبل از ارسال
- **جریان تامین** — داشبورد تامین، سریال، وضعیت per خط
- **Rebate** — سیستم کد تخفیف جدا از کوپن legacy
- **کراولر مشخصات** — GSM Arena / Zoomit
- **تضمین رجیستری** — برای دسته گوشی
- **سیاست خرده‌فروشی** — محدودیت یک واحد per مشتری
- **رویداد یلدا** — قالب چندصفحه‌ای کمپین
- **مهاجرت WordPress** — کاربر، محصول، سفارش، SEO
- **پipeline تلگرام** — scrape → JSON → import
- **چندفروشندگی** — تب فروشندگان روی صفحه محصول
- **نمودار قیمت** — تاریخچه قیمت با Chart.js
- **مقایسه** — سبد session-based تا ۴ محصول

## جمع‌بندی

**ایران حافظه** یک راه‌حل E-Commerce **کامل و فارسی‌محور** است که فراتر از یک فروشگاه ساده عمل می‌کند:

| لایه | آنچه پوشش می‌دهد |
|------|------------------|
| **مشتری** | مرور، جستجو، مقایسه، سبد، پرداخت، پیگیری سفارش |
| **مدیریت** | محصول، قیمت، سفارش، تامین، مالی، بازاریابی، SEO |
| **فروشنده** | فروش چندفروشندگی |
| **فنی** | درگاه بانکی، SMS/Push، API موبایل، حسابداری، import |

سیستم برای **فروش خرده‌ای B2C** در ایران بهینه شده: RTL، جلالی، OTP، کد ملی، استان/شهر، درگاه‌های داخلی، و ابزارهای عملیاتی مثل KYC و تامین.
