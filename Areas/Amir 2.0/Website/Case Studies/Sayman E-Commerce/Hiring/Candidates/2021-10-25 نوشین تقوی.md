## تخصص لاراول

**middleware ها را در لاراول توضیح دهید.**
برای فیلترکردن و چک کردن درخواست های ورودی یا خروجی به برنامه ها هستند که میتوانند برای هر درخواست یا بعضی از آن ها اعمال شود. برای مثال اهراز هویت کاربر ، چک کردن فعال بودن اکانت و ... به طور کلی انجام یک سری از اقدامات قبل از اکشن اصلی درخواست. middleware های خروجی نیز برای log انداختن یا چک کردن مدت زمان پردازش درخواست و ... استفاده شود

**چطور می‌تونیم از Validation ها استفاده بکنیم؟**
validation ها برای اعتبارسنجی ورودی های درخواست است. بهتر است که از Form Request Validation استفاده شود

**رابطه‌های polymorphic رو توضیح بدید.**
یه رابطه چند گانه هست که بین چند مادل ایجاد میشه برای مثال شما میتونید یک مادل image داشته باشید و با یه رابطه polymorphic توی هر مادلی که نیاز دارید بدون تغییر در مادل image ارتباط رو برقرار کنید

**فرض کنید نام و نام خانوادگی کاربر در دو فیلد جداگانه در دیتابیس ذخیره می‌شود، برای نشان دادن نام نمایشی کاربر که شامل هر دوی این فیلد‌ها هست از چه امکانی می‌توانیم استفاده کنیم؟**
میتوان از Accessor مدل user استفاده کرد.
public function getFullNameAttribute()
}
 return "{$this->first_name} {$this->last_name}";
}

**Query Scopeها را در مدل‌های Eloquent توضیح بدید**
Scope ها شبیه به فیلتر های از پیش تعیین شده هستند که به ما برای تمیز نگه داشتن کد و خوانا تر شدن query ها بسیار کمک میکنند این scope ها میتواند daynamic یا static باشد و اینکه نوع صدا زدن آن ها هم میتونه گلوبال باشد

**در پروژه‌هایی که داشتید با Queue در لاراول کار کردید؟ اگر بله توضیحی درباره نحوه استفاده و مساله‌ای که از صف برای حل اون استفاده کردید بدید**
برای انجام تسک های درخواست هایی که زمان بر هستند می توان از صف ها استفاده کرد. من برای ارسال بعضی از ایمیل ها از صف استفاده کردم یا برای انجام مجموعه کاری که باید در ساعت مشخصی انجام شود.

**کاربرد Resource Collectionsها در لاراول چی هست؟**
برای دستیابی به مجموعه ای از اطلاعات یا pagination میتوان از آن استفاده کرد. برای مثال اگر بخواهیم دیتاهای مدل x را برای کاربر ارسال کنیم میتوان کالکشن مورد نظر را ساخت حتی تغییراتی در ان اعمال کرد.

**با تست‌ها در لاراول آشنا هستید؟ چه نوع تست‌هایی در لاراول داریم؟ برای اجرای تست‌ها از چه دستوری استفاده می‌کنیم؟**
دو نوع تست اصلی داریم unit test و feature که مورد اول برای تست جداگانه هر پارت از سیستم با توجه به میزان خرد کردن اجزای سیستم توی تست با دید اینکه بقیه پارت ها سالم هستند انجام میشه و مورد دوم برای تست کردن یک فلوی کامل که از ورود ریکوئست به سیستم تا خروج اون هست استفاده میشه
