**middleware ها را در لاراول توضیح دهید.**
در واقع میدلور ها یک ولیدییشن بین کاربر و برنامه ماست که و ساده ترین میدلور رو که میتونم بهتون مثال بزنم میدلور is_admin هست که به طور مثال اگه کاربری خواست وارد پنل مدیریتی برنامه ما بشه - اگه مدیر بود وارد بشه - در واقع کد رو به شکل زیر باید بنویسیم توی میدلور - البته اینم بگم که توی دیتابیس مربوطه توی این نوع میدلور یه ستون برای صحت سنجی نیاز داریم:

    if (\Auth::user()->is_admin == true) {
         return $next($request);
       }

**چطور می‌تونیم از Validation ها استفاده بکنیم؟**
ساده ترین توضیحی که میتونم بهتون بدم این هست که اگه تعداد validate هامون خیلی زیاد شدن - ما میتونیم validate هایی که از پیش ساخته شده توسط خودمون استفاده کنیم - برای این کار دستور php artisan make:request name رو میزنیم و یه رگوئست ایجاد میکنیم و این رگوئست ایجاد شده میره توی فایل app/http/request و ما بعد از اینکه این فایل ایجاد شد باید وارد این فایل بشیم و rules ها و message های سفارشی خودمون رو بزاریم
البته برای استفاده از Request سفارش - توی فانکشن روت مربوطه - به جای pubf store(Request $request) از pubf store(CustomRequest $request) کنیم

**رابطه‌های polymorphic رو توضیح بدید.**
خب - ساده ترین مثال رو اینطوری میزنم - بر فرض مثال ما چندین پست تایپ داریم - مثلا ما پست معمولی داریم - محصول داریم - ویدیو داریم و و و
حالا ما مطمئنا یه جدول به نام دسته بندی داریم - دیگه اینطوری نمیشه کرد که واسه هر کدوم از این پست تایپ ها رابطه چند به چند معمولی تعریف کنیم
این موقع باید از رابطه چند به چند پلی مورفیک استفاده کنیم که به شرایط زیر خواهد بود

    categoriables
        category_id - integer

        categoriable_type - string

توی category_id - آیدی دسته بندی مربوطه میگیره
توی categoriable_id - آیدی اون پست یا ویدیو میگیره
و توی categoriable_type - اسم اون مدل به مثال app/model/posts
