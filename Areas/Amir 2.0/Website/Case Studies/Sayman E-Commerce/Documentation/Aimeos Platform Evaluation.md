# مستندات بررسی Aimeos — سیستم فروشگاهی مبتنی بر لاراول

> [!info] درباره این نوت
> ارزیابی فنی پلتفرم متن‌باز Aimeos به عنوان گزینه‌ای برای بازسازی فروشگاه سایمان دیجیتال روی لاراول (سپتامبر ۲۰۱۹) — شامل بررسی مستندات، افزونه‌های پولی/رایگان، و جمع‌بندی مشکلات عمده. مرتبط: [[Sayman E-Commerce Case Study]] · [[Sayman — Website Case Study]] · [[Laravel E-Commerce Platform Research]]

## معرفی

Aimeos یک سیستم فروشگاهی با هسته PHP است که بر روی فریم‌ورک‌های مختلفی ارائه می‌شود. با توجه به مخزن کدهای aimeos-core که هسته این سیستم فروشگاهی است به نظر می‌آید Aimeos از کلاس‌ها و پکیج‌هایی ساخته شده است که به خوبی طراحی شده‌اند و بر روی فریم‌ورک‌های مختلف قابل عرضه هستند. عموما این امکان عرضه بر روی فریم‌ورک‌های مختلف با استفاده از قدرت Composer امکان‌پذیر است.

Aimeos با استفاده از extensionهای خود از قدرت پایگاه داده Elasticsearch استفاده می‌کند. بنا به ادعای وب‌سایت Aimeos این سرویس می‌تواند تا یک میلیارد محصول را پشتیبانی کند و هر خروجی مانند جست‌وجو یا نمایش در دسته‌بندی‌ها و … از این تعداد محصول را در ۲۰ میلی‌ثانیه نمایش بدهد. توضیحات مربوط به این بخش که با نام gigacommerce شناخته می‌شود در ادامه مستند آمده است.

## بررسی مستندات قابل استفاده برای توسعه‌دهندگان

- در Youtube ویدیو آموزشی برای توسعه یا رفع مشکلات این سیستم وجود ندارد.
- ویکی مخزن کد لاراولی پروژه خالی است.
- ویکی مخزن کد aimeos-core خالی است.
- یک فروم اختصاصی روی وب‌سایت خود پروژه برای سوال و جواب دارند که شامل ۶۵۰ سوال می‌شود.
- تعداد کل صفحات برای کلمه aimeos در جست‌وجوی گوگل ۳۶ هزار صفحه است (برای مقایسه، تعداد صفحات گوگل برای کلمه woocommerce حدود ۴۲ میلیون است).
- نتیجه جست‌وجو برای کلمه aimeos روی استک‌اورفلو ۴۳ نتیجه در بر دارد.
- از آنجایی که این پروژه بر روی یک بیس PHP توسعه داده شده است، عموما Aimeos خود را ملزم به رعایت convention‌های کدنویسی لاراول نکرده است.

## بررسی extensionها

### ai-payments (FREE)

این افزونه، سیستم پرداخت را برای سیستم فروشگاهی Aimeos تسهیل می‌کند و برای پشتیبانی از راه‌های پرداختی مانند paypal و … توسعه داده شده است. با توجه به تفاوت ماهیت سیستم‌های بانکی این افزونه برای ما قابل استفاده نیست.

### Marketplace & Complex B2B (PAID: 1490 €)

افزونه‌ای که امکانات مورد نیاز برای استفاده از تامین‌کنندگان و تبدیل فروشگاه به مارکت‌پلیس را اضافه می‌کند.

### gigacommerce (PAID: 1490 €)

افزونه‌ای که با استفاده از Elasticsearch برای فروشگاه‌هایی که بالای ۵۰ هزار محصول دارند و همچنین از محصولات پیچیده پشتیبانی می‌کند. این افزونه سرعت بارگذاری، سرعت ناوبری سایت و سرعت جست‌وجو را در تعداد محصول بالا بهبود می‌بخشد.

سخت‌افزار مورد نیاز برای استفاده مطلوب از این افزونه بنا بر توضیحات خود وب‌سایت:

- 8 CPU Cores
- 16+ GB RAM
- 500 GB SSD

### ai-cache (FREE)

افزونه کش.

### Customer Groups (PAID: 249 €)

افزونه گروه‌بندی کاربران، نمایش متن یا عکس بر اساس گروه کاربری، محدودسازی دسته‌ها یا محصولات برای گروه‌های خاص، قیمت‌دهی محصولات بر اساس گروه کاربری.

### Ultra fast search with Solr (PAID: 490 €)

این افزونه با استفاده از قدرت Apache Solr امکانات زیر و موارد دیگری در زمینه جست‌وجو و ایندکسینگ را اضافه می‌کند:

- سرچ سریع و فیلترهای پیشرفته
- Full text search and indexing

### ai-filesystems (FREE)

لایه نگه‌داری فایل برای Aimeos که قابلیت نگه‌داری فایل‌ها روی فضای ابری و یا به صورت ریموت را دارد.

### VAT Calculator & VAT ID checker (PAID: 179 €)

محاسبه مالیات‌های VAT و چک کردن VAT ID.

### ai-mqueue

افزونه ایجاد صف از تسک‌های در حال اجرا که برای scale کردن پروژه به شدت مورد نیاز و قابل استفاده است.

## مشکلات عمده

- قابلیت‌های اصلی مورد نیاز ما از طریق افزونه‌های پولی تامین می‌شوند. همچنین این افزونه‌ها از قدرت نرم‌افزارهای آزاد و رایگان Elasticsearch و Apache Solr استفاده می‌کنند که در هر پروژه دیگری قابل استفاده است و محدود به استفاده از Aimeos نمی‌شود. هر چند باید در نظر داشت استفاده از این نرم‌افزارها نیازمند کسب دانش و تجربه در زمینه استفاده از این ابزارهاست که چه از طریق Aimeos و چه هر پروژه دیگری برای استفاده از این قابلیت‌ها تجربه و دانش فنی بیشتری نیاز هست.
- مستندات مورد نیاز برای توسعه‌دهنده بسیار کم بوده و عملا بیشتر مستندات فقط در قالب کدهای پروژه قابل مطالعه است.
- هزینه مربوط به خرید افزونه‌ها برای یک سال پشتیبانی و به‌روزرسانی است و برای دریافت به‌روزرسانی‌های بعدی نیازمند صرف هزینه بیشتر هستیم.
- برای توسعه بخشی از نیازهای فعلی و همسان‌سازی Aimeos با نیازهای فروشگاهی داخل ایران نیازمند توسعه خود این سیستم هم هستیم و با خرید و نصب افزونه‌ها هنوز به طور کامل یک سیستم فروشگاهی قابل استفاده نیست.
