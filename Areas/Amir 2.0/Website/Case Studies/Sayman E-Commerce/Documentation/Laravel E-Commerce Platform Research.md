# بررسی پلتفرم‌های فروشگاهی مبتنی بر لاراول

> [!info] درباره این نوت
> مقایسه‌ای کوتاه از چند پلتفرم فروشگاهی متن‌باز مبتنی بر لاراول (Bagisto، Aimeos، AvoRed، GetCandy، Vanilo) که در سال ۲۰۱۹، پیش از تصمیم به بازسازی سایمان دیجیتال با لاراول، به عنوان گزینه‌های آماده بررسی شده‌اند. سند اصلی صرفاً یک لیست خام از نکات کلیدی هر پلتفرم است، نه تحلیل نهایی. مرتبط: [[Sayman E-Commerce Case Study]] · [[Sayman — Website Case Study]] · [[Aimeos Platform Evaluation]]

## Bagisto

- Live Demo: https://demo.bagisto.com/
- Github Stars: 1514
- has JSON API
- Good Documentation
- Support for developing packages
- Laravel 5.6
- ماژول‌های پولی و گران
- Marketplace
- PWA
- POS

## Aimeos

- Live Demo: https://demo.aimeos.org/
- github Stars: 2027
- has JSON API for front end and admin
- Strong Documentation
- Support for Extensions
- Laravel 6
- Since 2015

## AvoRed

- Live Demo: https://demo.avored.com/
- Github Repository: https://github.com/avored/laravel-ecommerce
- Github Stars: 800
- Managed by one person
- Good Documentation

## GetCandy

- Github Stars: 155
- has Documentation

## Vanilo

- Github Stars: 315
- Seperate Packages for cart, product, ...
- has Documentation
